# Uploadio - AI-Powered Passport Photo & Image Tools

A modern, production-ready web application for AI-powered photo editing, passport photo generation, and image manipulation.

## 🚀 Features

- **AI Background Removal** - Remove backgrounds instantly with AI
- **Passport Photo Generator** - Create compliant passport photos for India, US, and custom sizes
- **Background Changer** - Change backgrounds with solid colors or custom images
- **Image Resizer** - Resize images to any dimension
- **Image Compressor** - Reduce file size while maintaining quality
- **Image Converter** - Convert between PNG, JPG, and WEBP formats
- **Face Detection** - Automatic face detection for perfect passport photos
- **Mobile First** - Fully responsive design for all devices
- **SEO Optimized** - Built-in SEO with meta tags, schemas, and sitemap
- **High Performance** - Lighthouse score 90+ with lazy loading and code splitting

## 🛠️ Tech Stack

- React 19
- Vite
- Tailwind CSS
- React Router DOM
- React Dropzone
- Fabric.js
- face-api.js
- @imgly/background-removal
- React Hot Toast
